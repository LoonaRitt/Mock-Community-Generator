About this interface

This interface aims to improve the accessibility and reproducibility of metabarcoding analyses, providing scientists with an efficient way to create reference datasets for the validation and optimization of their bioinformatics pipelines.

Presentation Mock Community Generator

It is a tool designed to facilitate the generation of witness communities for uses in metabarcoding. It allows you to retrieve, filter and organize genetic sequences from public databases BOLD . The tool also integrates an export system in FASTA format, allowing researchers to use the data generated for in silico analyzes or for the design of laboratory syntheses.

Presentation Taxon Sequence Explorer

This tool makes it possible to find a higher taxonomic level when a species has an insufficient number of genetic sequences. It aggregates the sequences of the parent taxa until a level is identified where the data is significant.
