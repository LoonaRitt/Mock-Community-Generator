About this interface

This interface aims to improve the accessibility and reproducibility of metabarcoding analyses, providing scientists with an efficient way to select mock community sequences for the validation and optimization of their bioinformatics pipelines.

Mock Community Generator

It is a tool designed to facilitate the generation of mock communities for uses in metabarcoding. It allows you to retrieve, filter and organize genetic sequences from public databases BOLD. The tool also integrates an export system in FASTA format, allowing researchers to use the data for in silico analyzes or for the design of laboratory syntheses. Taxon Sequence Explorer

This tool makes it possible to explore sequences from a higher taxonomic level when a species has an insufficient number of sequences. It aggregates the sequences of the parent taxa until a level is identified where the data is significant.
